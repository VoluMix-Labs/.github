<p align="center">
  <strong>VoluMix</strong> is a custom hardware + software volume mixer built as a personal project that brings together CAD/3D printing, PCB design and software engineering.
</p>

## Repositories

This project is split into three repositories:

- **Hardware**: [`VoluMix-Hardware`](../../../../VoluMix-Hardware)
- **Firmware**: [`VoluMix-Firmware`](../../../../VoluMix-Firmware)
- **Software**: [`VoluMix-Software`](../../../../VoluMix-Software)
- **Protocol**: [`VoluMix-Protocol`](../../../../VoluMix-Protocol)

## Getting started

- **Hardware**: See the hardware repo for CAD files, PCB files, BOM, and assembly notes.
- **Firmware**: See the firmware repo for flashing/build instructions.
- **Software**: See the software repo for install/run instructions.
